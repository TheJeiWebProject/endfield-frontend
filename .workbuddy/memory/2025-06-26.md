# 2025-06-26

## 加载动画 - 显示所有资源加载列表

**data.js Store**
- 新增 `loadingResources` 响应式数组，追踪每个文件的加载状态
- `loadData()` 拆分为三个独立资源条目：`data.json`(核心数据)、`endfield_blueprints.json`(蓝图数据)、`combined_icons`(组合图标)
- 每个资源有状态流转：`pending` → `loading` → `done`，附带进度百分比

**LoadingOverlay.vue**
- 替换单一文件信息卡片为资源列表
- 每行：旋转/完成/待定图标 + 中文名称 + 文件名 + 进度条
- done 状态切换为绿色图标和绿色进度条
- loading 状态青色边线 + 旋转图标
